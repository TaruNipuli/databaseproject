# Database Project

## Project description
This project is a simple online store application. 
Users can browse products and product categories, place orders, and view their own order history. 
The project is built with Spring Boot and MariaDB and uses a REST API and JPA to work with the database.

## Technologies
- Java
- Spring Boot
- MariaDB
- JPA (Java Persistence API)

## Database
The application uses a MariaDB database with the following tables:
- contacts
- customeraddresses
- customers
- order_log
- orderitems
- orders
- product_details
- productcategories
- products
- supplieraddresses
- suppliers

## Project structure
The project is structured as follows:
- controllers handle REST API requests 
- entities represent database tables
- repositories handle database operations
